구글시트에서 명단 불러오기

시트를 불러와 data/members.csv 파일을 만든 뒤, 터미널에서 npm run cards 를 실행하면 카드 HTML이 전부 다시 만들어집니다.

1. 구글시트 주소로 불러오기

시트가 “링크가 있는 모든 사용자 - 뷰어” 로 공유되어 있어야 합니다.

2. 엑셀 파일(.xlsx) 열기

구글시트에서 파일 > 다운로드 > Microsoft Excel(.xlsx) 로 받은 파일을 그대로 선택하세요.

3. 안 될 때는 직접 붙여넣기

구글시트에서 표를 드래그해 복사(Ctrl+C)한 뒤 아래에 붙여넣으세요. 첫 줄은 기수 / 이름 / 학원 머리글입니다.
