### 시작하려면 (딱 한 가지만 하면 됩니다)
NEIS 무료 API 키를 발급받아야 합니다. **가입 즉시 발급되고 비용은 없습니다.**

1. https://open.neis.go.kr 접속 → 회원가입(구글/네이버/다음 계정으로 간편가입) → 로그인
2. 상단 메뉴 **[오픈API]** → **[인증키 신청]** 클릭 → 바로 발급
3. 발급받은 키를 아래처럼 등록:
   - **실제 서비스(배포)**: 터미널에서 `npx wrangler pages secret put NEIS_API_KEY --project-name webapp` 실행 후 발급받은 키 붙여넣기, 또는 Cloudflare 대시보드 → Pages 프로젝트 → Settings → Environment variables에서 `NEIS_API_KEY` 추가
   - **로컬 개발**: `.dev.vars.example` 파일을 복사해서 `.dev.vars`로 저장한 뒤, 파일 안의 값을 발급받은 키로 교체

키를 등록하지 않으면 검색 시 "NEIS API 키가 설정되지 않았습니다" 안내 메시지가 표시됩니다.
