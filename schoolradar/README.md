# 스쿨레이더

학교알리미 공시자료를 받아 **분석 리포트 PDF 를 만드는 도구**입니다.
내 컴퓨터에서만 돕니다. 서버에 올리지 않고, 로그인도 접속 코드도 없습니다.

---

## 실행

윈도에서는 폴더 안의 **`스쿨레이더.bat` 을 두 번 누르면** 됩니다.
처음 한 번은 필요한 것을 내려받느라 몇 분 걸리고, 그다음부터는 바로 뜹니다.
검은 창을 닫으면 멈춥니다.

맥·리눅스거나 직접 띄우고 싶으면:

```bash
npm install          # 처음 한 번만
node dev.js          # http://localhost:3000
```

**Node.js 20 이상**이 필요합니다 (nodejs.org 에서 LTS).
포트를 바꾸려면 `PORT=3100 node dev.js`.

리포트를 만들려면 **클로드코드 CLI 가 설치돼 있고 Claude 구독 계정으로 로그인**돼 있어야 합니다.
`claude` 명령을 못 찾으면 `SR_CLAUDE_BIN` 환경변수에 전체 경로를 넣으세요.

## 화면 흐름

```
랜딩 (/)  →  학교 조회 (app.html)  →  저장소 (vault.html)
```

1. **학교를 이름으로 찾습니다.** 지역을 먼저 고르지 않습니다. 초성만 쳐도 됩니다 — `ㅎㅁㄱ` → 휘문고.
2. **고르면 기본정보가 뜹니다.** 동시에 `vault/{학교명}_{연도}/data/openapi.json` 이 만들어집니다.
3. **[공시 원문 파일] 에서 받습니다.** 전체 선택하고 누르면 하나씩 순서대로 받습니다.
   항목당 10초쯤 걸리고, 학업성취에서는 숫자 확인창이 한 번 뜹니다(중·고만).
4. **[리포트] 에서 PDF 를 만듭니다.** 브리프는 두 쪽에 몇 분, 종합은 스무 쪽에 수십 분입니다.
   종합은 [만들기] 를 누르면 목차 창이 먼저 열려 어느 절을 만들지 고를 수 있습니다.
   만드는 중에 창을 닫아도 계속 돕니다. 끊기면 같은 세션에 이어서 다시 시도합니다.
5. **[저장소] 에 전부 쌓입니다.** 받은 원문, 만든 PDF, 제작메모가 학교별 폴더에 들어갑니다.

```
vault/{학교명}_{공시연도}/
  raw/    공시 원문          out/    완성된 PDF, 제작메모.md
  data/   openapi.json 등    meta.json
```

브라우저가 아니라 **폴더에 쌓는 이유**는, 브라우저 안에 두면 클로드코드가 못 읽어서
리포트를 만들 수 없기 때문입니다.

## 1년에 한 번 할 일

색인 두 벌은 공시가 갱신될 때 다시 만듭니다. 평소에는 건드리지 않습니다.

```bash
node build-schools.js    # public/schools.json — 전국 학교 색인 (몇 분)
node build-kess.js       # public/kess.json, kess-ms.json, kess-es.json (몇 분, 약 90MB 내려받음)
```

`build-schools.js` 는 **학교알리미 OpenAPI 인증키**가 있어야 돕니다(아래 참고).
`build-kess.js` 는 `.kess-cache/` 에 원본을 쌓는데, 끝난 뒤에는 지워도 됩니다.

학교알리미는 **최근 3년치만 공시**합니다. 그 이전 자료는 이 도구로 받을 수 없습니다.

## 짓지 않고 받는 코드 — 열어서 읽되 다시 짜지 않는다

| 파일 | 하는 일 | 왜 씨앗으로 받나 |
|---|---|---|
| `api/gongsi.js` | 학교알리미 공시 화면에서 원문 파일을 받아 온다 | 사이트를 뜯어 알아낸 값이 박혀 있다. 짜게 하면 그럴듯한데 아무것도 못 받는 코드가 나온다 |
| `api/schoolinfo.js` | 학교알리미 OpenAPI 중계. **맨 위에 인증키를 넣는 자리**가 있다 | 키를 한 곳에만 둔다. 색인 생성기와 collect 도 여기서 가져간다 |
| `api/collect.js` | `data/openapi.json` 과 고교 `졸업생진로 CSV` 를 만든다 | 프롬프트가 이 두 파일의 필드명과 표 구성을 그대로 전제한다 |
| `build-schools.js` | 전국 학교 색인 `public/schools.json` 을 만든다 | 담을 학교(초·중·고, 폐교 제외)와 행 모양이 정해져 있어야 화면과 collect 가 맞물린다 |
| `build-kess.js` | 졸업생 진로와 학교 규모 색인 `public/kess*.json` 을 만든다. KESS 에서 직접 내려받는다 | 프롬프트가 `cols`(열 이름 순서)와 `agg`(구·시도·전국 집계)를 전제한다 |
| `public/catalog.js` | 받을 공시 항목 목록과 종합 리포트 목차 | 무엇을 받느냐와 어떤 절을 만드느냐가 곧 리포트의 입력이다 |
| `regions.json` | 시도·시군구 코드표 | `build-schools.js` 가 읽는다 |
| `package.json` | 의존성 (iconv-lite, exceljs) | |
| `public/favicon.*` | 아이콘 | |

여기에 더해 `prompts/`(리포트 지시문 5종), `docs/`(규칙서 5종), `docs/template/`(서식 정본)도
**리포트의 심장이라 고치지 않습니다.**

> **규칙은 하나입니다.** 클로드코드가 위 파일에서 에러를 만나면 코드를 고치게 하지 말고
> 에러를 그대로 보여 달라고 하세요. 고치는 순간 다른 사람의 리포트와 달라집니다.

화면과 서버는 이 규칙 밖입니다 — `dev.js`, `api/vault.js`, `api/report.js`,
`public/index.html`, `app.html`, `vault.html`, `style.css` 는 고쳐도 됩니다.
다만 화면이 그리는 **목록은 반드시 `catalog.js` 의 `SR` 에서만** 꺼내세요.

## 미리 알아두실 것

**인증키가 따로 필요합니다.** 학교 기본정보를 받아오는 데 학교알리미 OpenAPI 키가 필요합니다.
[학교알리미 → 알리미 소식 → OpenAPI](https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m0.do) 에서
네이버·카카오 계정으로 로그인하고 사용 목적을 등록하면 **무료로 바로** 나옵니다.
받은 키는 `api/schoolinfo.js` 맨 위 `API_KEY` 따옴표 안에 넣습니다.
`.env` 로 빼지 마세요 — `build-schools.js` 와 `api/collect.js` 가 이 상수를 가져다 씁니다.
**내 컴퓨터에서만 도는 도구라 키는 소스에 그대로 둡니다.**
(공공데이터포털 `data.go.kr` 의 학교알리미 데이터셋은 **다른 서비스이고 키도 다릅니다.**)

**KESS 파일은 스크립트가 직접 받습니다.** `node build-kess.js` 를 돌리면
최근 5개년 원본(합쳐 약 90MB)을 `.kess-cache/` 에 내려받습니다. 몇 분 걸립니다. 받은 뒤에는 지워도 됩니다.

**`docs/template/분석리포트_템플릿_정본.htm` 에는 특정 학교의 실제 수치가 예시로 들어 있습니다.**
이걸 그대로 쓰면 내 리포트에 그 학교 숫자가 남을 수 있습니다. 프롬프트가 마지막에
확인하라고 시키지만, 결과 PDF 를 한 번은 눈으로 훑어보세요.

**학교알리미는 최근 3년치만 공시합니다.** 그 이전 자료는 이 도구로 받을 수 없습니다.

**리포트는 두 종류입니다.**

| | 분량 | 걸리는 시간 | 읽는 자료 |
|---|---|---|---|
| 학교 브리프 | 두 쪽 | 몇 분 | 기본정보, 진로, 성취도만 |
| 종합 리포트 | 스무 쪽 | 수십 분 | 규정과 교육과정 첨부까지 전부 |

상담 직전에 필요한 건 대개 브리프입니다. 종합은 학교 하나를 제대로 파야 할 때 씁니다.

**리포트는 구독으로 돕니다.** 리포트 실행기는 클로드코드를 띄우기 전에
`ANTHROPIC_API_KEY` 같은 환경변수를 지웁니다. 남아 있으면 구독 대신 API 과금으로 붙기 때문입니다.
진행 기록에 찍히는 "사용량 $0.000 어치" 는 구독으로 돌아도 표시되는 환산값이지 청구액이 아닙니다.

## 잘 안 될 때

| 증상 | 조치 |
|---|---|
| 학교 검색이 비어 있다 | `node build-schools.js` 를 아직 안 돌렸거나 인증키가 없습니다 |
| 기본정보에 "인증키가 없습니다" | `api/schoolinfo.js` 맨 위 `API_KEY` 를 채우세요 |
| 리포트가 "claude 명령을 찾지 못했다" | `SR_CLAUDE_BIN` 에 `claude` 전체 경로를 넣으세요 |
| 리포트가 "서버가 다시 시작되어 진행 상태를 잃었습니다" | 서버를 재시작하면 진행 중이던 작업이 끊깁니다. 다시 만들면 됩니다 |
| 검은 창에 `EADDRINUSE` | 이미 다른 창에서 돌고 있습니다. 그 창을 쓰거나 닫고 다시 실행하세요 |
| 씨앗 파일에서 에러가 난다 | **고치지 말고** 에러를 그대로 들고 오세요 |
